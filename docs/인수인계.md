# 인수인계

작업을 마칠 때마다 아래 세 절을 갱신한다. 절 제목은 바꾸지 않는다(jelly-studio의 현황·이어가기가 읽는다).
"다음 할 일"은 맨 위가 가장 먼저 할 일이다. 채택한 키울 아이디어(`docs/아이디어.md`)는 여기로 옮긴다.

## 마지막 작업

- 2026-10-23 공개 사이트에서 내부 파일을 내렸다(`/crossgate` 무거움, 실행 기록 `ai-log/20261023/001_164803_block-internal-files`). Pages가 저장소 루트 대신 `dist/`를 배포하고, `npm run build`가 브라우저 파일 31개만 허용 목록대로 복사한다. 아직 배포 전이다. 운영에서는 배포할 때까지 `AGENTS.md`, `ai-log/`, `.crossgate/`, `docs/` 등이 계속 열린다.
- 2026-10-03 배포했다(`release` = `b3489b2b`, #27까지). 운영에서 PostHog 기록이 시작됐다. 배포 전 확인 조건이던 PostHog 계정 설정 둘은 확인하지 않고 배포했다(사용자 결정). 배포 점검 중 시험 이벤트 `$bot_probe_not_sent` 1건이 PostHog에 들어갔다. jelly-studio 지표가 세는 이벤트가 아니라 숫자에는 영향이 없다.
- 2026-10-03 PostHog 기록을 넣었다(`/crossgate` 무거움, 실행 기록 `ai-log/20261003/001_004527_posthog-tracking`). 이벤트는 `$pageview`, `core_action`(`place_open`), `$exception` 셋이고, 쿠키 고지를 첫 화면 footer에 넣었다. 동작과 사용자 결정은 [숫자 기록](숫자-기록.md) "평소보다" 절에 있다. jelly-studio 등록 문서(`jelly/register` 브랜치)도 같은 실행에서 검수했다.
- 2026-09-29 jelly-studio 목록에 등록했다(단계 `focus`).

## 다음 할 일

- 내부 파일 차단 배포. 순서: (1) Cloudflare Pages 대시보드에서 thanusual 프로젝트의 빌드 설정(Build command)을 `npm run build`로 바꾼다(지금 `release`에는 build 스크립트가 없으니 배포 직전에 한다), (2) `main`을 `release`로 fast-forward, (3) 운영 주소에서 `/AGENTS.md`, `/.crossgate/kit/VERSION`, `/ai-log/20260926/001_212957_pin-places/timeline.md`가 404이고 `/`, `/app.js`, 지도 타일이 정상인지 curl과 브라우저로 본다. 빌드 명령이 빠지면 빌드가 실패하고 이전 배포가 그대로 남는다.
- 배포 뒤 숫자 확인. 평소 브라우저나 휴대폰으로 운영 화면을 한 번 열고 몇 분 뒤 jelly-studio 루트에서 `python3 bin/jelly resume thanusual`을 돌려 방문자 수가 0보다 큰지 본다. 화면에 보이지 않는 창(백그라운드 탭, 숨은 앱 내 브라우저)에서는 PostHog가 첫 `$pageview`를 미루므로 방문으로 잡히지 않는다. 0이면 [숫자 기록](숫자-기록.md) "확인 방법"을 따른다.
- PostHog 계정 설정 확인. 둘 다 PostHog 화면에서 본다(저장소 밖): (1) 프로젝트 설정에서 방문자 IP 저장 끄기(Discard client IP data), (2) 결제 설정에서 무료 한도를 넘어도 추가 과금 없이 수집이 멈추는 상태인지. 한도에 닿으면 기록이 멈추고 숫자 누락을 허용한다.

## 열린 문제

- 차단을 배포해도 이미 공개된 사본은 남는다. 지난 배포의 고유 주소(`<hash>.thanusual.pages.dev`)는 옛 파일을 계속 서빙하므로 Pages 대시보드에서 옛 배포를 지워야 사라진다(되돌릴 수 없음, 사용자 판단). 검색엔진 색인은 404가 되면 점차 빠지고, 빨리 빼려면 Search Console 삭제 요청. GitHub 저장소가 공개라 같은 파일은 GitHub에서는 계속 보인다.
- 운영 기록이 시작됐는데 PostHog의 IP 저장 끄기와 과금 없는 한도 정지를 아직 확인하지 않았다. 확인 전까지는 방문자 IP가 저장되거나, 한도를 넘으면 과금될 수 있다(위 "다음 할 일").
- 방문자 수는 실제보다 적게 잡힌다. 쿠키를 차단한 브라우저에서는 PostHog를 불러오지 않고, 광고 차단기가 PostHog 요청을 막을 수 있다. 받아들인 한계다.
- PostHog 로더는 버전을 고정하지 않고 최신 SDK를 받는다(공식 로더의 동작). 숫자가 갑자기 0이 되면 SDK 쪽 설정 이름이 바뀌었는지부터 본다.
- 폭 320px 폰에서 쿠키 안내를 펼치면 그동안 목록이 약 50px로 줄어든다. 안내를 접으면 돌아온다.
