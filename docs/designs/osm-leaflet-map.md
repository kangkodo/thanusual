## Problem Statement

나가기 전에 서울 공식 핫스팟 121곳이 **지금 평소보다 붐비는지** 한 화면에서 보고 싶다. 장소 하나를 정한 뒤에는 네이버/카카오로 충분하다. 121곳을 한 번에 비교하는 도구는 없다. 평소보다 목록이 그 쐐기다. 지도는 같은 숫자의 두 번째 화면이다.

이윤(Meta/Google 광고)은 재방문이 생긴 뒤의 일이다. 지금 수요 증거는 만든 사람 본인뿐이다.

## Demand Evidence

- Q1: 사이트가 꺼지면 화낼 외부 사용자는 없다. 「사라지면 화낼 사람은 사실 나다.」
- 공개 URL은 있다 (`https://thanusual.pages.dev`). 방문자·재방문 수치는 이 세션에 없음.
- 광고·결제 증거 없음.

## Status Quo

장소 하나를 정하면 네이버/카카오를 연다. 「서울 121곳 중 지금 평소보다 붐비는 곳」은 그 앱에 없다. 진짜 경쟁자는 네이버 밑그림이 아니라 **한 핀만 보는 습관**이다.

## Target User & Narrowest Wedge

- 사람: 서울에서 나가기 전에 붐빔을 보는 사람. 현재 예시는 만든 사람.
- 쐐기: 목록을 깨지 않고, 같은 정렬 키로 도시에서 몰림을 보고 가까이에서 핀을 고른다.
- 광고는 재방문 증거가 있을 때 별 이슈.

## Constraints

- 목록이 첫 화면. 재작성·새 프레임워크·새 디자인 시스템 금지.
- 121곳. 런타임 소스는 `current.json`의 `places` (이미 lat/lng 포함). `places.json`을 지도에서 다시 불러 조인하지 않는다.
- Leaflet 래스터 타일만. 엔진을 MapLibre로 바꾸지 않는다. `tile.openstreetmap.org` 금지. OSM 저작권 표기는 한다.
- 네이버 검색·REST 키 없음. 광고 SDK 없음.
- 파일: `index.html`, `styles.css`, `app.js` + 벤더한 `leaflet.css`/`leaflet.js` (CDN 런타임 금지).
- 토큰: `#fff`, `#171717`, `--hot` `#c2410c`, `--calm` `#0f766e`, `--muted` `#525252`. 새 폰트·그라데이션 금지.

## Premises

1. 문제는 커스텀 지도 SDK가 아니라, 나가기 전 121곳 붐빔을 한눈에 보는 것이다.
2. 안 만들면 네이버 한 핀으로 돌아가고 121 비교는 없다. 타인 수요는 가설이다.
3. 지도는 기존 목록·스냅샷 위에 얹는다.
4. 배포는 이미 Pages다.
5. 광고는 재방문 다음.
6. OSM+Leaflet은 오버레이 엔진이다. 네이버 밑그림을 이기려 하지 않는다.

## Approaches Considered

### Approach A: 핀만

HTML 핀만. 도시 줌에서 121개가 겹친다. Effort S. 분포가 없다.

### Approach B: 줌 적응 분포+핀 (chosen)

멀리서는 목록과 **같은 정렬 키**로 크기·색 점. 가까이서는 HTML 핀. 목록↔지도. Effort M.

### Approach C: 네이버 링크

Leaflet 없음. Ruled out: 커스텀을 버림.

Ruled out this slice: `leaflet.heat`. 121 공식 점은 안개가 아니라 섬광이다. 분포는 크기 점으로 한다.

## Recommended Approach

**B, closed.** 분포 = 정렬 키로 그린 원. 히트맵 플러그인 없음.

### Decision table

| 항목 | 결정 |
|---|---|
| 보기 | 한 화면. 지도가 바탕, 순위 목록은 왼쪽 레일(데스크톱) 또는 아래 시트(휴대폰). `목록`/`지도` 전환 없음. |
| 분류 탭 | 그대로. `aria-label="장소 분류"`. 지도는 `rowsOf`와 같은 `state.cat`만 그린다. |
| 보기 전환 | 분류 탭 **아래**에 별 컨트롤. `aria-label="보기"`. 버튼 목록 / 지도. 기존 `.tabs`를 재사용하지 않는다. |
| 정렬·가중 | 목록과 동일: `RANK[level]` 내림차순, 그다음 `mid`. 평소 대비 %는 `warming`이 true면 지도에도 안 쓴다. |
| 원 크기 | `circleMarker`만. `weight: 1`. 페인트 여유→붐빔 (먼저 add). `BASE = {붐빔:22, "약간 붐빔":16, 보통:11, 여유:6}`. 같은 등급 peers의 mid min–max로 `t`, `radius = base*(0.8+0.4*t)`. mid 없거나 n<2 또는 min=max면 `base`. |
| 원 색 | 붐빔·약간 `--hot` fillOpacity 0.85 / 0.7. 보통 `--muted` 0.4 (밝은 타일에서 `--ink` 채우기 금지). 여유 `--calm` 0.25. |
| 줌 | 초기 `setView([37.55, 126.98], 11)`. `minZoom: 10`. `maxBounds: [[37.42, 126.76], [37.70, 127.18]]`, `maxBoundsViscosity: 1`. `z≤12` 위 원. `z≥13` 붐빔·약간만 24px `--hot` DivIcon. 보통·여유는 원 유지. `z≥13`에서 장소 이름을 핀/원 오른쪽에 붙인다 (박스 없는 라벨). |
| 높이 | `#map`은 헤더+배너(보일 때)+분류+보기 아래 남은 `100dvh`. `view=map`일 때 `footer` 숨김. 저작권은 Leaflet `attributionControl`. 헤더·탭 max-width 40rem. 지도 full-bleed. |
| 연동 | 행 클릭 → `view=map`, `setView([lat,lng], 14)` (항상 setView). 선택: `--ink` 2px 링 후 `bringToFront()`. 핀/원 클릭 → `view=list`, `li[data-name]` `scrollIntoView`. |
| 타일 | 클라이언트 `/tiles/{z}/{x}/{y}{r}.png` (`{r}`는 `""` 또는 `@2x`). Pages Function이 `CARTO_API_KEY`를 붙인다. git에 키 없음. osm.org 폴백 금지. 타일 실패 시 `#e5e5e5` + 오버레이. |
| 저작권 | attributionControl: `© OpenStreetMap © CARTO`. |
| 데이터 | `state !== "fresh"` 또는 lat/lng 없으면 그리지 않음. `state.data` 없으면 지도 버튼 disabled, Leaflet 마운트 안 함, 패인에 목록과 같은 「목록을 읽지 못했습니다」. 타일만 실패하면 지도 패인 `role="status"` 한 줄, 목록은 유지. |
| 전환 | 지도를 `display:none`에서 켤 때 `invalidateSize()`. |
| a11y | 목록일 때 skip → `#board`. 지도일 때 skip → `#map`. 보기 버튼 44px. |
| 모션 | `flyTo` 쓰지 않음. 항상 `setView`. |
| 벤더 | Leaflet 1.9.x `leaflet.css` + `leaflet.js`를 레포에 복사. |

Wireframe:

```
[평소보다]
지금 붐빔 순
[전체] [공원] …          ← 분류, 기존
[목록] [지도]            ← 보기, 새 줄

목록일 때: 지금 board
지도일 때: full-bleed #map, 원은 붐빔이 더 큼
```

## Success Criteria

- 도시 줌에서 큰 원·진한 색이 목록 상위(등급, 그다음 인원)와 같다.
- 행→지도, 핀→행이 같은 장소를 가리킨다.
- 타일이 막혀도 목록은 읽힌다. 데이터 없으면 지도가 안 뜬다.
- 광고·네이버 키·osm.org 타일 없음.
- 분류 탭·정렬·skip·44px·등급 글자가 목록에서 그대로다.
