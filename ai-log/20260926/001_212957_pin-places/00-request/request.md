# 요청 명세

## 사용자 목표
자주 보는 장소를 고정해 두고, 목록을 열면 그 장소들을 먼저 볼 수 있게 한다. (2026-09-26 사용자 요청: 파일럿 후보 1번 "관심 장소 고정")

## 확정 요구사항
- R-1: 목록의 각 장소 행에 고정/해제 버튼(☆/★)이 있다. 누르면 그 장소가 고정되거나 해제된다.
- R-2: 장소 상세 패널에도 같은 고정/해제 버튼이 있다.
- R-3: 고정한 장소가 하나 이상이면 목록 맨 위에 "고정한 장소" 구역이 나타난다. 없으면 구역 자체를 그리지 않는다.
- R-4: 고정 상태는 이 브라우저에 저장되어 새로고침·재방문 후에도 유지된다. 서버·계정 연동은 없다.
- R-5: 저장소를 쓸 수 없는 환경(사생활 보호 모드 등)에서도 페이지는 정상 동작한다. 고정은 그 탭에서만 유지된다.
- R-6: 목록 데이터에서 사라진 장소 이름이 저장돼 있으면 조용히 무시한다(오류 없음).
- R-7: 고정 구역 안의 순서는 아래 목록과 같은 정렬 규칙을 따른다(`CLAUDE.md`의 정렬 계약: warming 전 등급·인원 순, 전환 후 평소보다 순).
- R-8: 버튼은 키보드로 조작할 수 있고, 눌림 상태를 보조기술에 알린다(`aria-pressed`). 버튼 이름에 장소 이름이 들어간다.
- R-9: 기존 동작(행 클릭 → 선택·지도 이동, 휴대폰 바텀시트, 새로고침 시 포커스 유지, 분류 탭, 검색)은 그대로다.

## 하지 않을 일
- 지도 표시 변경 (`map.js` 수정 없음)
- 서버 저장, 계정, 공유 링크에 고정 목록 담기
- 금지 경로(`.pipeline/config.json`의 forbidden) 수정

## AI가 새로 가정한 것 (사용자 확인 완료)
- A-1: 고정 구역은 분류 탭·검색과 상관없이 고정한 장소를 항상 전부 보여준다.
- A-2: 고정한 장소는 아래 순위 목록에서도 그대로 보인다(순위 번호 유지). 고정 구역 행에는 순위 번호 대신 표시만 한다.
- A-3: 고정 개수 제한은 없다.
