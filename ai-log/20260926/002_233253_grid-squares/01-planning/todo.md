## 배경 사실 (기획 단계에서 확인함)
- `vendor/seoul-grid.geojson`의 10,125칸 ID는 모두 `다사XXXXYYYY` 형식의 국가지점번호다. 각 칸의 남서 모서리는 UTM-K(EPSG:5179) 좌표로 x0 = 900000 + XXXX·10, y0 = 1900000 + YYYY·10이다. 일반식은 x0 = 700000 + (첫 글자 순번)·100000 + XXXX·10, y0 = 1300000 + (둘째 글자 순번)·100000 + YYYY·10이고, 순번은 가나다라마바사아자차카타파하 순서로 0부터 센다.
- 파일의 점은 모두 남서 모서리 + (125m, 125m)이다. 표본 203칸에서 오차는 ±0.1m였고, 조사 에이전트는 공식 뷰어의 10,125칸 전체로 따로 검증했다.
- UTM-K: GRS80(a = 6378137, f = 1/298.257222101), 원점 위도 38°, 중앙 경선 127.5°, k0 = 0.9996, FE = 1,000,000, FN = 2,000,000.
- 지도는 `preferCanvas: true`이고 250m 모드는 줌 13 이상에서만 그린다(`PIN_ZOOM`).

## 상태 계약
- 250m 모드가 아니거나, 줌이 13 미만이거나, `grid.json` 또는 해당 시각 조각이 없거나, 격자 파일이 아직 안 읽혔으면 아무것도 그리지 않는다(지금과 같음).
- 화면에 조금이라도 걸치는 칸은 모두 그린다. 가장자리에서 칸이 잘려 빠지지 않게, 칸 중심이 화면 경계에서 한 칸(250m) 이내면 그린다.
- 값 있는 칸은 지금과 같은 잉크색이고, 투명도는 `0.2 + bandIndex·0.16`(하루 고정 분위수)이다. 비식별·자료 없음 칸은 중립색 0.12다. 0으로 보이지 않아야 한다.
- 시간 슬라이더를 움직이거나 지도를 이동·확대하면 기존 경로로 다시 그린다. 칸 모서리 계산은 칸마다 한 번만 하고 재사용한다.
