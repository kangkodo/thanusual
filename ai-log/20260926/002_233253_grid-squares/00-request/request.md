# 요청 명세

## 사용자 목표
250m 생활인구 지도를 더 세밀하게 보이게 한다. 지금은 칸마다 4px 점이라 칸 사이가 비어 있다. 칸을 실제 250m 정사각형으로 채워 어느 블록이 붐비는지 빈틈 없이 보이게 한다. (2026-09-26 사용자 지시: 조사 결과 표의 1번 "점 → 250m 정사각형")

## 확정 요구사항
- R-1: 250m 모드에서 각 칸을 공식 격자와 같은 250m 정사각형으로 그린다. 이웃 칸과 빈틈·겹침 없이 맞물린다.
- R-2: 경계는 칸 ID(국가지점번호, UTM-K/EPSG:5179)에서 계산한다. 새 데이터 파일이나 외부 요청을 추가하지 않는다.
- R-3: 비식별·자료 없음 칸은 0으로 보이지 않는다. 지금처럼 중립색으로 구분한다(`CLAUDE.md` "Null suppression is not zero").
- R-4: 색 규칙(하루 고정 분위수 5단계)과 시간 슬라이더 동작은 지금과 같다.
- R-5: 칸을 가리키거나 누르면 지금처럼 날짜·시각·격자 ID·인원(또는 비식별/자료 없음)이 보인다. "원은 실제 격자 경계가 아닙니다" 문구는 사실과 달라지므로 고친다.
- R-6: 지도 이동·확대가 지금보다 눈에 띄게 느려지지 않는다.

## 하지 않을 일
- 시간 해상도 변경(3시간 → 1시간), 수집기·데이터 형식 변경 (다음 작업)
- 외국인 인구 합산, 다른 데이터 출처 추가
- 보간·번짐 표현
- 금지 경로 수정
