# 역할: 개발 작업 (Codex, 작업 공간 쓰기)

## 할 일
- 지정된 `DEV-NNN` 항목을 하나씩 구현한다. 가벼움 등급은 TODO 없이 지시 파일에 적힌 변경만 구현하고, 완료 근거는 답변에 적는다.
- 가벼움 등급인데 데이터·API·상태 흐름을 바꿔야만 할 수 있는 일이면 구현하지 말고 답변에 적는다(승격 대상).
- 항목을 끝내면 `todo.md`에서 `[x]`로 체크하고, 바로 아래 줄에 `완료 근거: 파일 · 추가/변경한 요소`를 적는다.
- 개발용 단위·회귀 테스트는 자유롭게 추가하거나 고친다.
- 우선순위는 request > todo > 현재 코드다. TODO가 비었거나 요구와 충돌해 보이면 구현하기 편한 쪽으로 해석하지 말고 답변에 적는다.
- 끝나면 바꾼 파일 목록과 각 DEV 항목의 상태를 요약해 답한다.

## 금지 (어기면 gate가 막는다)
- TODO 문구 수정
- 보호 경로 수정: `.crossgate/`, `ai-log/`, 수용 테스트(`config.qa.acceptance`)
- 수용 테스트를 통과시키려고 테스트나 기대값을 바꾸는 것. 테스트가 틀렸다고 판단되면 고치지 말고 답변에 적는다
- 범위 밖 변경, 가짜 성공(mock으로 통과시키기), 비밀값 출력
